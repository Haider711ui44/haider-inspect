# حيدر 711 X — واجهة أولية

واجهة React/Vite متعددة اللغات (العربية والإنجليزية والروسية) مع:
- لوحة تحكم عربية RTL، وتبديل تلقائي لاتجاه الصفحة.
- معاينة منشورات تستخدم `{number}` لتغيير الرقم.
- إعداد رقم البداية والنهاية والزيادة والفاصل الزمني.
- أقسام أولية للمتابعين وسجل النشاط والإعدادات.

## التشغيل
1. ثبّت Node.js إصدار LTS.
2. فك ضغط المشروع وافتح مجلده في الطرفية.
3. نفّذ `npm install`.
4. نفّذ `npm run dev` ثم افتح الرابط المحلي الذي يظهر.

## ما لم يُفعّل بعد
هذه واجهة أولية وليست خدمة نشر فعلية. تسجيل الدخول والنشر يتطلبان تطبيق X Developer، وتكوين OAuth 2.0 PKCE، وخادم Backend آمنًا لحفظ الرموز، ومراجعة صلاحيات X API وخططها وحدودها الحالية. زر تسجيل الدخول معطّل عمدًا حتى لا يوحي بوجود اتصال غير مهيأ. لا تضع Client Secret أو رموز الوصول في كود المتصفح.

ميزة إدارة المتابعين في هذه النسخة للعرض والتحليل فقط؛ لا تنفذ متابعة أو إلغاء متابعة آليًا ولا تخفي الأتمتة. كما يجب التحقق من سياسات X الحالية قبل جدولة أي محتوى متكرر.
