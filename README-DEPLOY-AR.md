# نشر حيدر 711 X على Render

## ما تحتويه هذه الحزمة
واجهة React + Vite بثلاث لغات (العربية والإنجليزية والروسية)، وملف `render.yaml` لتسهيل نشر الواجهة كـ Static Site على Render.

## النشر
1. فك ضغط الملف على جهازك.
2. أنشئ مستودعًا جديدًا في GitHub باسم `haider-711-x`.
3. ارفع **محتويات المجلد** إلى المستودع (يجب أن يكون `package.json` و`render.yaml` في جذر المستودع).
4. افتح https://dashboard.render.com/ وسجّل الدخول.
5. اختر New ثم Blueprint، واربط مستودع GitHub الذي رفعت إليه المشروع.
6. وافق على إنشاء الخدمة `haider-711-x` وانتظر اكتمال النشر.
7. بعد نجاح النشر سيظهر رابط عام بصيغة `https://haider-711-x.onrender.com` (قد يختلف الاسم إذا كان محجوزًا).

يمكن أيضًا إنشاء Static Site يدويًا باستخدام:
- Build Command: `npm install && npm run build`
- Publish Directory: `dist`

## تنبيه مهم قبل ربط X
هذه الحزمة تنشر **واجهة الموقع فقط**. تسجيل الدخول الحقيقي عبر X، وحفظ رموز OAuth، والنشر المجدول يحتاج إلى خادم خلفي آمن وقاعدة بيانات؛ هذه المكونات غير موجودة في النسخة الأصلية الحالية. لا تضع Client Secret أو Access Token في ملفات الواجهة أو GitHub.

بعد ظهور رابط Render الحقيقي، استخدم رابط HTTPS العام في خانة Website URL في لوحة مطوري X. أما Callback URL فيجب أن يطابق حرفيًا مسار الخادم الخلفي بعد نشره؛ لا تستخدم عنوان localhost كعنوان موقع عام، ولا تغيّر Callback إلى عنوان تخميني قبل تجهيز الخادم.
